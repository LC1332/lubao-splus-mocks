# 食物搭配与不同总价练习运行说明

## 生成练习卷

在项目根目录执行：

```bash
python3 -m pip install -r src/requirements.txt
python3 src/generate_food_pairings.py --count 12 --total-price-count 3 --seed 20261014 --output-dir generated
```

本题型固定生成 12 道题，其中第 4、8、12 题明确询问不同总价，其余 9 道保留参考题“不同价格的搭配方法”问法。题数和问法配额不能通过参数放宽。`--seed` 控制商品、单价及题序；相同种子与参数会复现相同题目内容。`--output-dir` 可指定输出目录。

生成器最多尝试 250000 个候选。候选须同时满足两组数量下限、同组异商品同价、跨组相同非零价格差、不同总价不超过 10 种、价格均为 10～49 元，以及进位与不进位覆盖等要求。12 道数学价格配置按两组可交换的含重复次数价格列表去重；若达不到完整题数，程序会报错且不会保存不完整练习卷。

## 输出文件

- `generated/大班数学食物搭配练习.docx`：12 道练习及卷末参考答案。练习部分每页 2 题；答案逐题列出全部配对总价矩阵、去重后的总价、同价商品例子和相同非零价格差的同价例子。
- `generated/食物搭配素材/题目数据与答案.json`：种子、配置、两组商品、完整配对列表、不同总价、答案、去重键、两类同价证据及整卷验证摘要。
- `generated/食物搭配素材/q01.png` 至 `q12.png`：每道题使用的两组食物图示和标价，图片由本地绘图生成，无需联网素材。

再次运行会更新这些同名食物搭配文件，不会修改其他题型的练习卷。程序使用项目已有依赖 `Pillow` 与 `python-docx`，无需更改依赖清单。

## 计算与校验说明

程序保留每件商品的独立 ID，即使两件商品价格相同也分别参与所有配对。先枚举两组的全部商品配对，再对配对总价去重；学生题目答案是不同总价的种数，不是商品搭配总数，也不是不同单价配对数。

每次生成会在保存前从最终商品价格重新复算配对、总价和答案，并检查指定重复单价商品、另一组不同单价、价格差见证、组内数量、总价上限、题目去重、问法配额和题目数量组合变化。生成的数据还记录进位与不进位覆盖结果。

项目根目录已经有 `Pillow` 与 `python-docx` 的依赖说明，首次运行可使用上面的安装命令。如果系统缺少中文字体，题目图片优先使用 macOS 苹方 / 华文黑体或 Noto CJK；图中的中文可在安装其中一种字体后重新生成。Word 中的题设和说明也以嵌入图片方式保证常见环境下显示中文。
