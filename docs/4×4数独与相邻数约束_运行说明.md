# 4×4 数独与相邻数练习运行说明

## 生成练习卷

在项目根目录执行：

```bash
python3 -m pip install -r src/requirements.txt
python3 src/generate_adjacent_sudoku.py --count 12 --seed 20261014 --output-dir generated
```

默认生成 12 题，随机种子为 `20261014`，输出到项目根目录下的 `generated/`。可用 `--count` 指定 1 至 12 题、`--seed` 复现抽题结果，或用 `--output-dir` 指定其他输出目录。相同种子和配置会生成相同题目与顺序；更换种子会重新抽取类别和题目。

生成器会完整枚举 4×4 行列合法解，按所有 24 条公共边生成红线模式，再从题面唯一已知数和红线约束中重新求解。只有恰好一个解的题目才会进入候选池。每题独立以 50% 概率抽取“含顺序行列”类别；不会把整卷固定成 6＋6。两类候选池在抽题前分别检查至少有 12 道不同题，容量不够时会停止并说明原因。

## 输出文件

- `generated/大班数学4×4数独与相邻数练习.docx`：6 页练习题和卷末参考答案。
- `generated/4×4数独与相邻数素材/题目数据与答案.json`：种子、题面红线矩阵、已知数、唯一解、类别和图片文件名。
- 同一素材目录内的 `q01.png` 至 `q12.png`：题目棋盘；`q01_answer.png` 至 `q12_answer.png`：答案棋盘。

重复运行会更新上述同名数独文件，不影响其他题型文件。中文规则文本会绘制为图片嵌入 Word，以避免阅读设备缺少中文字体时出现方框字。图片生成优先使用苹方、华文黑体或 Noto CJK 字体；若在新系统上出现中文缺字，请安装其中一种中文字体后重新生成。

## 验证

项目使用 Python 3.12.14 验证。逻辑测试命令：

```bash
python3 -m unittest discover -s src/tests -p 'test_adjacent_sudoku.py' -v
```

测试覆盖红线双向约束、1 与 4 不相邻、不增加 2×2 宫格限制、四种顺序行列、循环排列、无解/唯一解/多解识别、固定种子复现、题目去重、两类各 12 题容量及 10,000 次独立类别抽样的比例。生成后的 DOCX 另经 LibreOffice 渲染逐页检查，预期 9 页：6 页练习及 3 页答案。
