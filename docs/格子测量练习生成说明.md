# 格子测量练习生成说明

本项目会生成 12 道大班数学格子测量题，每题测量两个物品，并在 Word 末尾附参考答案。物品图和尺子均由程序绘制，答案按两条虚线之间的格子间隔数计算。

中文题干、标题和答案文字以高清透明文字图片放入 Word，避免没有中文字体的预览环境显示方框；文字图片带有可读的替代文本。测量图也作为图片嵌入。

## 运行环境

Python 3.10 或更新版本。安装绘图与 Word 文件依赖：

```bash
python3 -m pip install -r src/requirements.txt
```

## 运行

在项目根目录执行：

```bash
python3 src/generate_grid_measurement.py
```

默认使用固定随机种子 `20261014`，输出 Word 与绘图素材到 `generated/`。要换一组物品图样顺序，可指定种子：

```bash
python3 src/generate_grid_measurement.py --seed 42
```

也可以指定输出目录：

```bash
python3 src/generate_grid_measurement.py --output-dir /path/to/output
```

## 输出内容

- `generated/大班数学格子测量练习.docx`：A4 练习卷，每页两题，末尾附答案。
- `generated/格子测量素材/q01_first.png` 等：每次测量对应的图片，共 24 张。
- `generated/格子测量素材/题目参数与答案.json`：题目物品、尺子可见范围、起点和答案。

## 出题规则

- 第一次测量用完整尺子，尺子数字位于格子中央，物品起点不在尺子最左端。
- 第二次测量用两端截断的局部尺子，从非零刻度开始显示连续数字；测量起点也为非零位置，答案为 6～9 格。
- 端点虚线、物品轮廓端点和尺子格子分界线共用同一坐标。长度由两条虚线之间的间隔数决定。
- 素材在杯子、盘子、书本、橡皮、饼干、简单图形等生活物品与几何化图形之间变化。
- `--seed` 控制物品和配色的可复现排列；题目长度与端点位置定义在 `create_spec` 函数中。

调整题目或插图后重新运行脚本即可重建 Word 和配套素材。
