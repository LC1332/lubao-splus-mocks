# 方格中的图形面积与单位换算练习生成说明

## 运行环境

Python 3.10 或更新版本。安装 Pillow 和 python-docx：

```bash
python3 -m pip install -r src/requirements.txt
```

程序通过坐标直接绘制图形，不需要 AI 图像生成服务。中文题干和答案会作为带有替代文本的高清文字图片嵌入 Word，避免缺少中文字体时出现乱码；题目图形也嵌入 Word，不依赖外部图片路径。

## 生成

在项目根目录运行：

```bash
python3 src/generate_grid_area.py --count 12 --seed 20261014 --output-dir generated
```

- `--count`：题数，默认 12。
- `--seed`：随机种子，默认 `20261014`。相同种子与配置会生成相同题目、图形、答案及题序。
- `--output-dir`：输出目录，默认项目根目录下的 `generated/`。

程序在达到指定题数之前会持续筛选符合约束的图形；如果尝试次数耗尽仍无法生成足量题目，会报错，不会输出一份题数不足的练习卷。

## 输出

- `generated/大班数学方格面积与单位换算练习.docx`：A4 纵向练习卷。默认 12 题，每页 2 题，末尾附参考答案。
- `generated/方格面积与单位换算素材/题目数据与答案.json`：每题坐标、单位值、分项面积、答案、相连关系、校验结果和输出文件映射。
- `generated/方格面积与单位换算素材/q01_left.png` 至 `q12_left.png`：左图题图。
- `generated/方格面积与单位换算素材/q01_right.png` 至 `q12_right.png`：右图题图。

重复运行会更新上述同名成品和素材，不影响 `generated/` 内其他题型文件。

## 题目规则与面积计算

- 左图为 7×7 方格，每题由 3～9 个整格和 6～14 个对角线半格组成；半格数默认取偶数，使最终答案为整数。
- 右图为 8×7 方格，恰有 5 个格点三角形。每个三角形最小轴对齐包围矩形为 3×3、3×2、2×3 或 2×2，并满足任务书规定的角点和边点条件。
- 每题左图单位值与右图单位值分别为 1 和 2；默认各 6 题。每题左图保持较简单，右图保持较复杂。
- 两图分别检查整体共享顶点连通、内部无面积重叠、图案不进入左上角单位值标记格。右图的所有颜色都计入面积。
- 三角形使用行列式计算两倍面积，以整数累计后再换算单位值；不数斜线经过的格子，不对面积四舍五入。
- 图案几何数据与成图来自同一题目对象，答案由最终坐标复算。

## 文件说明

- `src/generate_grid_area.py`：命令行入口、题目数据汇总及输出流程。
- `src/grid_area_logic.py`：格点几何、面积计算、图形构造、连通与重叠校验、去重。
- `src/grid_area_render.py`：题图绘制和 Word 排版。
- `src/tests/test_grid_area.py`：面积基准、半整数三角形、重叠判定、批量生成与复现检查。

可在项目根目录运行以下命令检查几何计算与固定种子生成：

```bash
python3 -m unittest src.tests.test_grid_area -v
```
