# 组合图形数正方形生成器运行说明

## 生成练习卷

在项目根目录执行：

```bash
python3 -m pip install -r src/requirements.txt
python3 src/generate_square_count.py --count 12 --seed 20261014 --output-dir generated
```

程序会在 `generated/` 中生成 `大班数学组合图形数正方形练习.docx`，并在 `generated/组合图形数正方形素材/` 中保存 12 张题图和 `题目数据与答案.json`。重复运行会覆盖同名输出。

参数说明：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--count` | `12` | 生成 1～12 道题；整卷验收使用 12 道 |
| `--seed` | `20261014` | 固定随机种子可复现矩阵、题序和答案 |
| `--output-dir` | 项目根目录的 `generated/` | Word 与题图数据的输出位置 |

生成过程最多尝试 200,000 个候选。若不能按全部约束得到指定题数，程序会报错并停止，不会放宽条件或把不完整题集当作成功结果。

## 题目数据和校验

每道题的 JSON 数据包括完整 5×6 矩阵、保留格数量、1×1 至 5×5 分类计数、正方形起点清单、总数、规范去重键和校验结果。四邻接连通、完整 3×3、不规则包围矩形、无内部空洞，以及可见线段围出的正方形集合与完整格子区域计数一致，均在写入时检查。

题图由 Pillow 绘制，黄色格子和黑色格线按保留矩阵生成。Word 中的中文文字以 300 DPI 透明图嵌入，避免缺少中文字体的环境显示方框；题目图形本身按 300 DPI 输出。Word 为 A4 纵向版式，练习区每页 2 题，末尾另附分类答案。

## 依赖与中文字体

依赖已列在 `src/requirements.txt`：Pillow 和 python-docx。生成题图及 Word 不需要在线服务。中文文字渲染器依次尝试 macOS 苹方、华文黑体和 Linux Noto CJK 字体；如目标机器均无这些字体，需在 `src/generate_square_count.py` 的 `cjk_font` 候选列表中增加本机可用的中文字体路径。

## 运行逻辑校验

```bash
PYTHONPATH=src python3 -m unittest discover -s src/tests -p 'test_square_count.py' -v
```

用例覆盖 5×6 完整网格与孤立 3×3 的分类基准、删格影响、四邻接连通、可见空框拒收，以及固定种子复现和对称图形去重。
