# 立体积木匹配题运行说明

本程序按固定方向生成 12 道四选一题。每题要同时满足积木数量为 6、底面格子与地板完全相同，并通过墙洞。默认穿墙规则为“投影不超出洞口”，可以与洞口边缘贴合，投影低于洞口也能通过。选项不可旋转或镜像。

## 运行环境

Python 3.10 或更新版本。项目沿用 `src/requirements.txt` 中的 Pillow 和 python-docx：

```bash
python3 -m pip install -r src/requirements.txt
```

## 生成练习卷

在项目根目录运行默认命令：

```bash
python3 src/generate_block_matching.py --count 12 --seed 20261014 --output-dir generated
```

更换 `--seed` 可生成另一套可复现的题目、颜色和选项顺序：

```bash
python3 src/generate_block_matching.py --count 12 --seed 42 --output-dir generated
```

`--count` 支持 1 到 12 题，`--output-dir` 可指定输出目录。题目默认每页 1 道，卷末另起参考答案页。`--wall-rule pass` 是默认规则；如使用 `--wall-rule exact`，题干会改为要求正面轮廓与墙洞完全一致。

## 输出文件

- `generated/大班数学立体积木匹配练习.docx`：A4 练习卷，含姓名和日期栏、12 道题及逐选项参考答案。
- `generated/立体积木匹配素材/`：地板图、墙洞图、四个积木选项图和生成数据。
- `generated/立体积木匹配素材/题目参数与答案.json`：每题目标格坐标、墙洞格坐标、选项高度矩阵、全部立方体坐标、每块积木颜色、各项判定、选项字母和图片文件名。

每次生成会覆盖输出目录中的同名题卷和素材。请先复制需要保留的旧版本。

## 结构和答案规则

积木用高度矩阵表示，每个位置由地面连续堆叠，因而没有悬空块或重叠块；每个组合还需整体面相连。判定程序按三维坐标统计数量和占地，并将所有前后排积木投影到墙洞平面。每题恰有一个选项满足三项条件，其他选项按已重新计算的真值只满足一项或两项。

答案字母由种子决定并在 12 题中均衡分布，A、B、C、D 各 3 次。若候选池不能满足本轮配置，程序会报错并停止，不会生成不完整试卷。

## 检查生成数据

用任意文本编辑器打开 `题目参数与答案.json`。每道题的 `options` 内包含 `height_matrix`、`blocks`、`cube_colors`、`cube_count`、`floor_ok`、`wall_ok`、`truth` 和 `is_answer`。`truth` 的三位顺序为数量、地板、墙洞；例如 `101` 表示数量和墙洞满足、地板不符。

程序逻辑检查可运行：

```bash
python3 -m unittest discover -s src/tests -v
```
